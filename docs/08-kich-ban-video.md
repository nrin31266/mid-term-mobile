# Quay video demo MemberDesk

Sinh viên tự quay và bổ sung link video vào bài nộp. Chỉ cần quay đủ chức năng, khoảng 5–7 phút.

## Phím quay trên laptop KDE

**Meta (phím Windows) + Shift + R**: bắt đầu/dừng quay vùng bằng Spectacle; chọn vùng màn hình trái. **Meta + Ctrl + R**: quay cửa sổ. Đây là phím mặc định trong Spectacle đang cài trên máy; cấu hình cá nhân không có mục đổi phím quay. Nếu chưa nhận phím, mở Spectacle → Recording hoặc gán trong System Settings → Keyboard → Shortcuts → Spectacle. Chưa bấm thử để tránh gián đoạn công việc.

## Các chức năng cần xuất hiện

- Đăng nhập sai, đăng nhập đúng; cuối video đăng xuất và thử vào lại.
- Web: thêm hồ sơ đủ bốn trường và ảnh, hiện/ẩn mật khẩu lúc nhập, mở chi tiết rồi tải lại.
- Sửa tên/email/ảnh, để trống để giữ mật khẩu hoặc đặt mật khẩu mới; thử email trùng.
- Tìm tên không dấu, lọc có/không ảnh, sắp xếp, chuyển trang và trường hợp không có kết quả.
- Android: chọn ảnh thư viện, cắt ảnh; mở camera/chụp; lưu và mở lại hồ sơ. Làm mới web để thấy cùng dữ liệu. Nếu thuận tiện, quay thêm hủy chọn ảnh hoặc mất mạng rồi thử lưu lại.
- Xóa hồ sơ vừa tạo để quay: mở xác nhận, hủy một lần rồi xác nhận; tải lại tìm không còn.
- JSON: chọn file sai thấy lỗi, chọn file đúng xem trước rồi nhập, cho thấy số thêm/bỏ qua; xuất JSON. Android mở chọn file và hộp chia sẻ, không cần gửi đi.
- Mở thẻ thành viên trên web/Android; web bấm In / Lưu PDF.
- Firebase Console: document đúng `email`, `matkhau`, `hoten`, `hinhanh`, file ảnh trong Storage. Kết thúc bằng GitHub và gói Word/JSON/ảnh.
